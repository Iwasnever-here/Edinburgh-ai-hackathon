## Getting Started

### Backend

The Spring Boot backend runs without a database. Requests, offers, airline profiles, and strategy settings are held in memory and reset when the backend restarts.

```bash
cd backend
./mvnw spring-boot:run
```

### Backend API (in-memory demo)

Money values use integer pence. Request and offer IDs are strings generated by the backend.

| Method | Endpoint | Purpose |
|---|---|---|
| `POST` | `/api/requests` | Publish a flight request |
| `GET` | `/api/requests` | List requests |
| `GET` | `/api/requests/{requestId}` | Get one request |
| `GET` | `/api/airlines` | List demo airline profiles |
| `GET` | `/api/airlines/{airlineId}/marketplace` | List open requests for an airline |
| `POST` | `/api/requests/{requestId}/offers` | Submit an airline bid |
| `GET` | `/api/requests/{requestId}/offers` | List offers for the judges' view |
| `GET` | `/api/requests/{requestId}/standing?airlineId=...` | Get an airline's rank without competitor prices |
| `GET` | `/api/airlines/{airlineId}/bids` | Get an airline's bid history |
| `PUT` | `/api/airlines/{airlineId}/strategy` | Update an airline's demo strategy |
| `POST` | `/api/offers/{offerId}/accept` | Accept a valid offer |

Example request body:

```json
{
  "origin": "EDI",
  "destination": "BCN",
  "earliest": "2027-07-12",
  "latest": "2027-07-16",
  "passengers": 2,
  "maxPricePence": 15000,
  "checkedBags": 1,
  "directOnly": false
}
```

Example offer body for `POST /api/requests/{requestId}/offers`:

```json
{
  "airlineId": "aeronova",
  "pricePence": 12000,
  "checkedBags": 1,
  "direct": true
}
```
